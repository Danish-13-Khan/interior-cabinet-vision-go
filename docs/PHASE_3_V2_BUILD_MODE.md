# Phase 3 — V2 Build in 2D

**Status:** Complete

## Delivered

- V2 Build mode constrains the left rail to the structural **Build** tool.
- The structural panel exposes room dimensions, wall selection, doors, windows,
  opening dimensions, and plan-underlay import/calibration.
- The right inspector remains contextual to the selected room/object.
- The bottom status bar retains snap, grid, validation, millimetres, and
  fit-to-view zoom status.
- Existing save/open/autosave commands continue to operate on the same
  `InteriorProject` document in V2.

## Acceptance path

1. Create a Blank Room in V2 Project Home.
2. Enter Build mode.
3. Set width, depth, and height; add a door or window; optionally import a plan.
4. Save the project, reopen it, and verify room/opening data is retained.
5. Confirm the status bar reports grid, snap, units, zoom, and validation.
