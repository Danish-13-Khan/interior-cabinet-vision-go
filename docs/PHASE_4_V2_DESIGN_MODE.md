# Phase 4 — V2 Design + Dimensions

**Status:** Complete

## Delivered

- V2 Design mode limits the rail to Cabinets, Furniture, Materials, and Layers.
- Catalog placement, plan selection, drag-move, resize, rotation, duplicate,
  deletion, alignment, and cabinet-run commands reuse the shared editor.
- The contextual inspector is shared by Plan and Model and edits the canonical
  W × H × D values in millimetres.
- Cabinet presets provide 1200, 1500, 1800, and 2100 mm wardrobe sizes.
- Cabinet door style, door count, and material slots remain editable from the
  same inspector.
- Existing plan validation and millwork schedule derive from the same project
  document, so no V2-only geometry or size state exists.

## Acceptance path

1. Enter V2 Design mode and place a cabinet from the catalog.
2. Select, drag, resize, rotate, duplicate, and delete it in Plan.
3. Choose a common W × H × D preset and update a material/configuration field.
4. Switch to 3D and verify the same object, size, material, and selection.
5. Open Render and verify the millwork schedule lists the matching dimensions.
