# Phase 7 — Render Studio

Render Studio turns the canonical interior project into client-ready visual output.

## Workflow

1. Choose a saved project camera in the camera rail. Each viewpoint is persisted with the project and gets a generated thumbnail.
2. Pick a lighting recipe and either **Draft Preview** for fast iteration or **High Quality** for a presentation-sized image.
3. Render the active view, then export the PNG, a standalone presentation PDF, or the full client package (PDF, PNG, JSON, and accepted still provenance).

The selected camera, materials, scene geometry, lighting recipe, and resolution stay under the same project model used by the 2D and 3D editor.
